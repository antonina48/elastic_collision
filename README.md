## Описание проекта
Программа представляет собой графическое приложение на базе объектно-ориентированного подхода. Она визуализирует физический механизм абсолютно упругого столкновения круглой частицы с плоскими границами экрана. Вектор движения и скорость рассчитываются автоматически с использованием двумерной системы координат.

## Функциональные возможности
### Основной функционал
- 🏃 Физически корректный расчет траектории движения частицы.
- 💥 Реализация упругого отскока от всех четырех границ окна с учетом радиуса объекта.
- 🎨 Плавная анимация со стабильной частотой обновления кадров (~60 FPS).

### Дополнительный функционал (Интерактивность)
- ⏸️ **space (Пробел)** — приостановка и возобновление анимации (пауза).
- 🔄 **R / r** — мгновенный сброс параметров и генерация новой частицы со случайной скоростью и координатами.

## Требования к системе
- **Python:** Версия 3.9 или выше.
- **Операционная система:** Windows / macOS / Linux.
- **Библиотеки:** Используются исключительно встроенные модули (`tkinter`, `random`). Дополнительная установка внешних пакетов не требуется.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd elastic_collision
```

### 2. Создание и активация виртуального окружения
**На Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Запуск программы
```bash
python main.py
```

### 4. Управление в игре
- `space` — поставить анимацию на паузу.
- `R` — сгенерировать новый случайный шар.
